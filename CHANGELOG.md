# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Distribution verification in CI, including wheel installation and source
  distribution content checks.

## [0.1.0] - Unreleased

### Added

- A stage-oriented run model for retrieval, reranking, generation, citation,
  and evaluation traces.
- JSON, OpenTelemetry/OpenInference, and `msmarco-genqa` ingestion paths.
- Markdown and HTML diagnostic reports for individual runs, comparisons,
  conversations, quality evaluation, and configuration-sensitive failures.
- Reviewed failure labels, claim-level diagnosis, and a documented failure
  taxonomy.
- Reproducible toy and BEIR SciFact workflows with executable reports.
- Evals-as-code examples, artifact versioning guidance, and container support.
